# Andrej Karpathy

AI researcher and educator; author of the [[llm-wiki|LLM-Wiki]] pattern that
this project is built on.

## Notes

Published the "LLM Wiki" gist as an intentionally abstract *idea file* — meant
to be handed to an LLM agent (Claude Code, Codex, etc.) and instantiated
collaboratively rather than copied as a fixed implementation.
