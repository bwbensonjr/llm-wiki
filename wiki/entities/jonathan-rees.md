# Jonathan Rees

A Scheme designer and implementer. He was a member of the Yale project that built [[t-programming-language|T]], and with [[richard-kelsey|Richard Kelsey]] he built [[scheme-48|Scheme 48]]. He described its module system in [[another-module-system-for-scheme|Another Module System for Scheme]]. That system has interfaces, a separate configuration language, a static linker that builds standalone heap images, and a development environment where configurations can be changed while a program runs. With [[william-clinger|William Clinger]] he wrote "Macros That Work" (1991), which introduced the Strong Hygiene Condition and fed into R4RS ([[hygienic-macros]]), and he co-edited the Revised^4 Report on Scheme.
