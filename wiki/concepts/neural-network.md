# Neural Network

A model built by composing many simple neuron-like units — each computing a
weighted sum of its inputs plus a bias, usually followed by a nonlinearity —
arranged in connected layers.

## Notes

The [[perceptron]] is the smallest building block; stacking neurons so one unit's
output feeds the next lets a network learn relationships that a single straight
line cannot. Modern architectures such as the [[transformer]] — the basis of the
[[large-language-model|large language model]] — are large neural networks built
from these same weight-and-bias units.
