# Lean Proof Assistant

Lean is a programming language and proof assistant used to express definitions
and machine-check proofs about them. In [[formal-methods|formal methods]], it
can establish properties for every input covered by a theorem, complementing
tests over particular examples.

[[lexifina|Lexifina]] uses Lean for [[legislation-formalization|legislation formalization]]:
checking evidence of drafting faults and proving properties
of an executable income-tax model. Such proofs establish consequences of the
formal definitions; the translation from statutory language into those
definitions still needs independent scrutiny.
