# Plotnine

A [[python|Python]] [[data-visualization|data visualization]] library
implementing the [[grammar-of-graphics|grammar of graphics]], with an API
closely modeled on R's [[ggplot2|ggplot2]].

## Notes

- Plots are composed declaratively: `ggplot(data, aes(...))` plus geoms, facets,
  scales, and themes combined with `+`.
- Emphasizes sensible automatic defaults that remain fully overridable.
