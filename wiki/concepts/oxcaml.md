# OxCaml

[[jane-street|Jane Street]]'s extended dialect of [[ocaml|OCaml]], used as a
proving ground for advanced [[type-systems|type-system]] features (e.g.
preventing data races at the type level).

## Notes

- Cited as evidence for the value of strong type-level guarantees when
  programming with [[agentic-coding|agents]].
- Jane Street's control over the language is a stated reason it can pursue
  proof-oriented techniques others cannot.
